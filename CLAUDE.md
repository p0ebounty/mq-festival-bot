# MQ Bot — Telegram AI-агент для фестиваля

> Читай этот файл первым. Детальные правила — в `.claude/rules/`.
> Текущее состояние работы — **всегда** в `docs/STATE.md`.

## 1. Что это

Telegram-бот для фестиваля центра «Лидер» × MagnaQore.
Участник фотографируется/загружает фото и получает себя в «профессии будущего»,
либо одной фразой перестраивает выданный ему «базовый мир». Результат отдаётся
как картинка + **QR-код** для скачивания и репоста.

**Главный принцип продукта: бот — это ОДИН диалог, а не меню.**
Никаких каскадов кнопок, вложенных меню и «шагов визарда». Пользователь пишет
человеческим языком — LLM-агент сам понимает намерение и вызывает нужный tool.
Кнопки допустимы только как *ускоритель* (подсказка), но любой сценарий обязан
проходиться чистым текстом.

## 2. Стек

| Слой | Технология |
|---|---|
| Бот + API | Node 22, TypeScript, **grammY**, Fastify |
| Агент | Anthropic SDK → `https://api.kie.ai/claude` (`claude-opus-5`) |
| Генерация картинок | kie.ai Jobs API, `nano-banana-2` |
| БД | PostgreSQL 16 + Drizzle ORM |
| Админка | Next.js (App Router), React, Tailwind, **shadcn/ui** |
| Прокси/TLS | Traefik (уже развёрнут на сервере, `/docker/traefik`) |
| Пакетный менеджер | pnpm (workspaces) |

## 3. Окружения

Два независимых бота и два независимых стенда.

| | dev | prod |
|---|---|---|
| Домен | `bot-dev.example.com` | `bot.example.com` |
| Запуск | systemd + hot-reload | Docker Compose |
| БД | `mqbot_dev` | `mqbot_prod` |
| Telegram | отдельный бот-токен | отдельный бот-токен |

Один домен обслуживает **всё** для своего стенда: `/tg/<secret>` — вебхук бота,
`/api/*` — REST, `/` — админка.

**Никогда** не тестируй на prod. Никогда не смешивай токены/ключи окружений.

## 4. Незыблемые правила

1. **Секреты — только в `.env`** (в `.gitignore`). В коде и в git — никогда.
   Все новые переменные обязаны появиться в `.env.example` с описанием.
2. **kie.ai всё делает асинхронно.** `createTask` → `taskId` → callback/polling.
   HTTP 200 ≠ готово. Никогда не жди результат синхронно.
3. **Медиа у kie.ai живёт 14 дней.** Любой результат немедленно перекладывается
   в наше хранилище. Ссылку kie.ai пользователю не отдаём.
4. **Никаких браузерных `alert`/`confirm`/`prompt`/`<select>`/нативной валидации**
   в админке. Только кастомные компоненты (shadcn/ui). См. `.claude/rules/30-admin-ui.md`.
5. **Промпт пользователя не переписывается с нуля.** Агент чинит опечатки и
   достраивает техническую обвязку, но смысл и авторский посыл сохраняет дословно.
   См. `.claude/rules/20-bot-agent.md`.
6. **Миграции БД — только через Drizzle**, руками схему в проде не трогаем.
7. **Traefik уже стоит.** Не ставим Caddy/nginx, не занимаем 80/443.
8. После каждого значимого шага — обновить `docs/STATE.md`.

## 6. Команды

```bash
pnpm install          # установка
pnpm dev              # dev-стенд с hot-reload
pnpm build            # сборка
pnpm db:generate      # сгенерировать миграцию из схемы
pnpm db:migrate       # применить миграции
pnpm lint && pnpm typecheck
```
