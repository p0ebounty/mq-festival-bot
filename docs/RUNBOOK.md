## Первые 30 секунд: что вообще происходит

```bash
./scripts/smoke.sh prod
```

Одиннадцать проверок: жив ли процесс, отвечает ли домен, валиден ли
сертификат, работает ли редирект, поднята ли база. Если всё зелёное —
инфраструктура в порядке, проблема в логике.

Дальше — **админка**: `https://bot.example.com`. Дашборд отвечает на
вопросы «сколько сейчас в работе», «какая доля сбоев», «хватает ли
кредитов». Он обновляется сам, перезагружать не нужно.

## Частые беды

### Бот молчит

```bash
systemctl status mqbot-prod-bot
journalctl -u mqbot-prod-bot -n 50 -o cat
```

Сервис перезапускается сам (`Restart=always`). Если он в цикле падений —
в журнале будет причина. Ручной перезапуск:

```bash
systemctl restart mqbot-prod-bot
```

Проверить, что Telegram знает, куда стучаться:

```bash
TOKEN=$(grep -E '^TELEGRAM_BOT_TOKEN=' /srv/mqbot-prod/.env.prod | cut -d= -f2)
curl -s "https://api.telegram.org/bot$TOKEN/getWebhookInfo" | jq
```

В ответе важны три поля: `url` — наш домен; `pending_update_count` —
если растёт, бот не разгребает; `last_error_message` — если там что-то
есть, читать в первую очередь. Вебхук ставится сам при старте.

### Картинки не приходят

1. **Кредиты кончились?** Дашборд, плитка «Кредитов kie.ai». Бот сам
   пишет владельцу, когда остаётся меньше порога (настройка
   «Порог тревоги по кредитам»), но проверить стоит глазами.
2. **Задачи висят?** Плитка «Сейчас в работе». Числа в десятках при
   пустом зале — kie.ai не отвечает.
3. Раздел **Генерации**, фильтр по сбоям: в карточке видно, что именно
   ответила модель.

Потерянные задачи добирает воркер: он опрашивает kie.ai по задачам
старше 90 секунд, даже если callback не пришёл. Токены за сбой
возвращаются автоматически.

### Участник жалуется, что списали токены

Раздел **Участники** → карточка. Там движение токенов по строкам: за что
списали, за что вернули, когда. Если сумма журнала разошлась с балансом,
карточка скажет об этом прямо — значит баланс двигали мимо репозитория.

Начислить руками — там же, кнопкой. Действие пишется в аудит.

### Бот отвечает не то

Раздел **Диалоги** → переписка. Под каждым ответом агента раскрываются
вызовы инструментов: что он передал, что получил, сколько это заняло.
Это и есть ответ на вопрос «почему он так решил».

Промпт живёт **в коде** (`packages/core/src/agent/prompt.ts`), из админки
не правится. Изменение промпта = выкат.

### Кто-то злоупотребляет

Карточка участника → «Забанить». Бот перестанет отвечать сразу же.

Бонусы за репост: раздел **Репосты**. Если слабые подтверждения начали
раздавать токены зря — настройка «Лимит слабых подтверждений» в 0
(Настройки → Экономика). Применяется без рестарта.

## Выкат и откат

```bash
./scripts/deploy-prod.sh master        # выкатить свежий master
./scripts/deploy-prod.sh v1.2.3        # выкатить конкретный тег
```

Скрипт печатает коммит, который выкатывает, и в конце гоняет smoke.
Если smoke не прошёл — стенд считается неготовым, и это видно сразу.

**Откат** — тот же скрипт с прошлым тегом. Перед выкатом полезно
запомнить текущий:

```bash
git -C /srv/mqbot-prod log --oneline -1
```

## Бэкапы

Дампы в `/var/backups/mqbot`, хранение 14 дней. Прод — каждые 4 часа,
dev — раз в сутки (`/etc/cron.d/mqbot-backup`).

```bash
/usr/local/bin/mqbot-backup prod      # снять прямо сейчас
ls -la /var/backups/mqbot             # что есть
```

Восстановление:

```bash
systemctl stop mqbot-prod-bot mqbot-prod-admin
gunzip -c /var/backups/mqbot/mqbot-prod-ГГГГММДД-ЧЧММСС.sql.gz \
  | psql "$(grep -E '^DATABASE_URL=' /srv/mqbot-prod/.env.prod | cut -d= -f2-)"
systemctl start mqbot-prod-bot mqbot-prod-admin
```

Дамп снимается с `--clean --if-exists`, поверх существующей базы
разворачивается без ручной подчистки.

⚠️ **Медиа в дамп не входят** — это файлы на диске. Полный бэкап это
дамп + `/var/lib/mqbot/prod/media`.

## Перед фестивалем — чек-лист

- [ ] `./scripts/smoke.sh prod` — 11 из 11.
- [ ] Кредитов kie.ai хватает: дашборд или `pnpm kie credits`.
      Прикидка: одна картинка ≈ 8 кредитов.
- [ ] **Хештеги** проставлены настоящие (Настройки → Шаринг). По умолчанию
      там заглушка.
- [ ] Цифры экономики подтверждены: стартовый баланс, цена генерации,
      бонус за репост.
- [ ] `ops.alertChatId` — telegram id того, кому писать про кредиты
      (узнать у [@userinfobot](https://t.me/userinfobot)).
- [ ] Бэкап снят вручную перед началом.
- [ ] Один сквозной прогон на **prod**-боте: фото → профессия → QR →
      публикация → бонус.
- [ ] На проде НЕТ учётки `e2e` (она только для автотестов на dev):
      `psql "$DATABASE_URL" -c "select login from admin_users"`.

## Чего в системе нет — не искать

- **Ручной модерации.** Бот автономен, заявки на бонус не согласовываются
  (ADR 0007). Раздел «Репосты» — журнал, а не очередь.
- **Правки промпта из админки.** Только через выкат.
- **Голосовых.** Убраны (ADR 0009), бот отвечает отказом.
- **Подписанных ссылок на медиа.** `/media/<uuid>` открыт по угадыванию
  UUID, что практически невозможно, но это не то, что записано в правиле
  безопасности. Известный долг.
