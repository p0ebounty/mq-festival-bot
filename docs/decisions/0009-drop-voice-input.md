# ADR 0009 — Отказ от голосовых сообщений

**Статус:** принято · 2026-08-27
**Отменяет:** раздел «Голосовые» в системном промпте, `ingestVoice` в `bot/media.ts`,
поле `AgentMessage.audioDataUrls`.

## Что было

Бот принимал голосовые и кружки: Telegram отдаёт `ogg/opus`, мы гнали его
через `ffmpeg` в mp3 16 кГц моно и клали data-URL в блок `image_url` запроса
к модели. Трюк недокументированный, найден опытным путём — Gemini понимал
речь именно так, отдельный `input_audio` работал у flash и не работал у pro.

## Почему убрали

После перехода мозга агента на модели OpenAI (`gpt-5-5`, Responses API —
см. ADR 0008) этот путь **перестал работать**. Аудио в блоке `input_image`
Responses API не принимает.

Живой прогон 27.08.2026, 06:28 — участник наговорил голосовое:

```
06:28:23 INFO  голосовое перекодировано  oggBytes:154136 mp3Bytes:45405
06:28:26 ERROR агент не смог ответить    err:"ChatProviderError: провайдер: HTTP 400"
```

Участник увидел «Не получилось обдумать ответ. Попробуй ещё раз» и потерял
полминуты. `ffmpeg` при этом отработал штатно — деньги и время сгорели на
заведомо отвергаемом запросе.

## Варианты, которые рассматривались

| Вариант | Почему нет |
|---|---|
| Отдельный STT-сервис | У kie.ai распознавания речи нет вообще. Заводить второго провайдера ради удобства, которого нет в ТЗ, — новый ключ, новый счёт, новая точка отказа. |
| Держать Gemini только ради голоса | Два мозга в одном диалоге: разный тон, разное качество работы с инструментами. Владелец выбрал OpenAI именно за инструменты. |
| Вернуться на Gemini целиком | Хуже выбирает инструменты — ровно та проблема, из-за которой переключались. |

## Решение

Голосовые и кружки обрабатываются общим обработчиком неподдерживаемых типов:
бот сразу отвечает «Голосовые я не разбираю — напиши текстом, и сразу
возьмусь», без обращения к модели и без `ffmpeg`.

Это честно: отказ за 200 мс лучше, чем 3 секунды ожидания и «что-то пошло
не так».

## Последствия

- `ffmpeg` больше не нужен ни в dev, ни в prod-образе.
- Требование ТЗ это не нарушает: **фестивальный сценарий целиком проходится
  текстом**, голос там нигде не заявлен.
- Если STT когда-нибудь понадобится, точка расширения — `bot/media.ts`
  и новое поле в `AgentMessage`; в истории git есть рабочая реализация
  перекодирования (коммит `1f5b8be`).
