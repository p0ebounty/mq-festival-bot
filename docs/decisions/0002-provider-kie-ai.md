# ADR 0002 — kie.ai как единственный провайдер моделей

**Статус:** принято · 2026-08-26 · **частично отменено ADR 0008** (Claude-эндпоинт kie.ai не работает; мозг агента переведён на gemini-3-flash)

## Контекст
Владелец указал kie.ai. При изучении документации выяснилось, что kie.ai отдаёт
не только генерацию картинок, но и **Anthropic-совместимый** чат-эндпоинт
`https://api.kie.ai/claude` + `/v1/messages` с полной поддержкой
`tools` / `input_schema` / `tool_use` / SSE, модель `claude-opus-5`.

## Решение
Через kie.ai идёт **и мозг агента, и генерация картинок**, по одному API-ключу.
- Чат: официальный `@anthropic-ai/sdk` с `baseURL: https://api.kie.ai/claude`.
- Картинки: Jobs API, модель `nano-banana-2`.

## Последствия
- Плюс: **один ключ на всё** — ровно то, что нужно для требования «быстро
  сменить ключ провайдера из админки»; смена чинит сразу и агента, и картинки.
- Плюс: используем официальный SDK, а не самописную обёртку — меньше кода,
  меньше багов в стриминге и tool-use.
- Плюс: `baseURL` — одна строка, поэтому переезд на прямой Anthropic API или
  другого провайдера дешёв.
- Минус: единая точка отказа. Документация сама предупреждает, что стабильность
  «чуть ниже официальных провайдеров».
  → Митигация: `StorageAdapter` и клиент провайдера за интерфейсом; мониторинг
  кредитов; на фестивале — заранее проверенный запасной ключ.
- Минус: медиа у kie.ai живёт **14 дней** → обязательное копирование к себе.

## Проверенные факты API
- Авторизация: `Authorization: Bearer <KEY>`, `Content-Type: application/json`.
- `POST /api/v1/jobs/createTask` → `{code, msg, data:{taskId}}`.
- `GET /api/v1/jobs/recordInfo?taskId=` → `state: waiting|queuing|generating|success|fail`,
  `resultJson: '{"resultUrls":[...]}'`.
- `GET /api/v1/chat/credit` → остаток кредитов (используем для кнопки
  «Проверить ключ» в админке).
- Коды: 401 нет доступа, 402 нет кредитов, 422 валидация, 429 лимит,
  501 генерация упала, 455 обслуживание.
- Лимит: 20 новых задач / 10 секунд на аккаунт.
- `nano-banana-2` принимает `image_input` (до 14 изображений) → **одна модель
  закрывает оба сценария ТЗ**, отдельная модель для редактирования не нужна.
