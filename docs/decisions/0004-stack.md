# ADR 0004 — Стек и структура репозитория

**Статус:** принято · 2026-08-26

## Решение
pnpm-монорепо, TypeScript strict, ESM, Node 22.

```
apps/bot     Fastify + grammY — вебхук, REST, /g/ страницы, callback kie.ai
apps/admin   Next.js App Router — админка
packages/core  агент, tools, клиент kie.ai, storage, QR
packages/db    Drizzle: схема, миграции, репозитории
packages/config типизированный env + настройки из БД
```

## Обоснование
- **grammY**, а не telegraf: живее развивается, лучше типы, удобные плагины
  (rate limit, session), нативно работает через вебхук на Fastify.
- **Fastify**, а не Express: быстрее, схемы/валидация из коробки, TS-first.
- **Drizzle**, а не Prisma: SQL-первый подход, нет отдельного движка запросов,
  миграции — обычный SQL, который можно прочитать глазами перед выкатом на прод.
- **Next.js App Router + shadcn/ui**: требование владельца по React/Next;
  shadcn даёт полностью кастомные компоненты — ровно то, что нужно для запрета
  нативных браузерных элементов (ADR 0005 не нужен, требование в
  `.claude/rules/30-admin-ui.md`).
- **Монорепо**: бот и админка делят схему БД и типы. Дублировать их между
  двумя репозиториями — гарантированный источник рассинхрона.

## Последствия
- Один `pnpm install`, общие типы, общий линт.
- `apps/bot` и `apps/admin` — разные процессы: разный рантайм и цикл сборки,
  но один домен (маршрутизация по путям в Traefik).
