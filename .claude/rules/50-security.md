# Безопасность

## Секреты
- `.env` не коммитится. `.env.example` — коммитится, но **без значений**.
- Ротация ключа kie.ai возможна из админки без рестарта (значение в БД
  перекрывает `.env`; в `.env` — только bootstrap-значение).
- Ключ kie.ai в БД хранится зашифрованным (AES-256-GCM, ключ шифрования —
  `SECRETS_ENC_KEY` из `.env`). В API админки наружу отдаётся только маска
  (`sk-...abcd`), полное значение — никогда.

## Telegram
- Вебхук на `/tg/<WEBHOOK_SECRET>` + проверка заголовка
  `X-Telegram-Bot-Api-Secret-Token`. Запросы без него — 401.
- Rate limit на пользователя (см. `20-bot-agent.md`).

## kie.ai callback
- Callback-эндпоинт публичный → обязательна проверка подписи по
  `docs/vendor/kie/common-api_webhook-verification.md`.
- Плюс сверка `taskId` с нашей БД. Неизвестный `taskId` — 404, не обрабатываем.

## Админка
- Один аккаунт `admin`, пароль — **argon2id**. Схема пользователей уже
  многопользовательская (таблица `admin_users`), чтобы добавить второго без миграции логики.
- Сессии — httpOnly + Secure + SameSite=Lax cookie. Не localStorage.
- Rate limit на логин: 5 попыток / 15 мин на IP.
- Все мутирующие эндпоинты — CSRF-токен.

## Данные пользователей
- Фото участников — персональные данные. Хранить в приватном хранилище,
  отдавать только по подписанной ссылке с TTL.
- В админке фото видно, но скачивание логируется в `audit_log`.
- Ретеншн: удаляем медиа старше N дней (по умолчанию 30), настраивается.
