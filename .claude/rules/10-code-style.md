# Код-стайл

## Общее
- TypeScript **strict**. `any` запрещён, есть `unknown` + сужение типа.
- ESM (`"type": "module"`), Node 22.
- Все внешние границы (Telegram update, HTTP body, ответ kie.ai, env)
  валидируются через **zod**. Не доверяем ничему извне.

## Ошибки
- Свои классы ошибок в `packages/core/src/errors.ts`.
- Ошибка, которую увидит пользователь, обязана быть человекочитаемой по-русски.
  Технические детали — в лог, не в чат.
- Никаких «проглоченных» `catch {}`. Либо обработали, либо пробросили.

## Логи
- Структурные (pino), JSON. Обязательные поля: `env`, `userId`, `requestId`,
  `tool`, `taskId` — там, где применимо.
- **Никогда** не логируй: bot token, kie.ai key, session cookie, полное фото
  пользователя (только ссылка на наше хранилище).

## Именование
- Файлы `kebab-case.ts`, типы/классы `PascalCase`, функции/переменные `camelCase`.
- Таблицы БД — `snake_case`, множественное число (`users`, `generations`).

## Импорты
- Внутри монорепо — только через workspace-алиасы (`@mq/core`, `@mq/db`).
- Циклические зависимости между пакетами запрещены.

## Тесты
- Vitest. Обязательно покрываются: парсер интентов агента, обвязка kie.ai
  (createTask/poll/ошибки), биллинг токенов.
