# Тестирование

## Принцип

**Ничего не сдаётся «на глаз».** Каждый слой имеет автоматическую проверку,
которую можно запустить одной командой. Если фича не проверена автоматически —
она не готова.

## Уровни

| Уровень | Инструмент | Что покрывает |
|---|---|---|
| Unit | Vitest | промпт-билдеры, парсинг ответов kie.ai, экономика токенов, крипто настроек |
| Integration | Vitest + testcontainers/локальный PG | репозитории БД, миграции, идемпотентность callback |
| API (smoke) | `scripts/smoke.sh` | health, маршрутизация Traefik, сертификат, редирект 80→443 |
| E2E веб | Playwright (Chromium уже установлен) | вход в админку, страница настроек, проверка ключа |
| E2E бот | `scripts/bot-e2e.ts` | реальные вызовы Telegram Bot API к **dev**-боту |

## Тестирование бота без человека

У dev-бота есть API-доступ. Проверяем так:

- **Исходящее** — `sendMessage`/`sendPhoto` от имени бота в тестовый чат,
  проверяем, что доставлено (`message_id` в ответе).
- **Входящее** — не эмулируем Telegram, а бьём **прямо в наш вебхук**
  корректно сформированным `Update` (с заголовком
  `X-Telegram-Bot-Api-Secret-Token`), затем проверяем результат в БД:
  появилось ли сообщение, какие `tool_calls` записаны, что ушло в ответ.
  Это честнее и быстрее, чем гонять трафик через Telegram.
- Фикстуры апдейтов — `apps/bot/test/fixtures/updates/*.json`.

**Никогда** не тестируем на prod-боте.

## Тестирование веба

Playwright + Chromium. Обязательный минимум на каждую страницу админки:
1. страница открывается, нет ошибок в консоли;
2. рендерится в тёмной и светлой теме;
3. формы отдают ошибки **своими** компонентами (проверка требования
   «никаких браузерных валидаций»: у `<form>` есть `noValidate`,
   в DOM нет `<select>`, не вызываются `alert/confirm/prompt`).

Последнее — отдельный автотест `admin/test/no-native-ui.spec.ts`, он же
страховка от случайного нарушения требования заказчика.

## Внешние вызовы в тестах

- kie.ai по умолчанию **замокан** (записанные фикстуры ответов).
- Реальные вызовы — только в помеченных `@live` тестах, запускаются вручную
  (`pnpm test:live`), тратят кредиты. В CI не идут.

## Команды

```bash
pnpm test           # unit + integration
pnpm test:e2e       # Playwright
pnpm test:live      # реальные вызовы kie.ai (тратит кредиты!)
./scripts/smoke.sh dev   # проверка живого стенда
```
